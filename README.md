# Warung Management App

A simple web-based inventory and invoice management system for a warung.

## Struktur Proyek

- `index.html` - antarmuka pengguna utama.
- `styles.css` - styling tema gelap dan layout responsif.
- `app.js` - logika inventory, transaksi, upload Excel, dan dashboard.

## Cara Menjalankan

1. Buka folder proyek di terminal.
2. Mulai server lokal:
   ```bash
   python3 -m http.server 8000
   ```
3. Buka `http://localhost:8000` di browser.

## GitHub

git branch -M main
